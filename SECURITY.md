# Security Policy

## Supported Versions

We provide security patches and updates for the following versions of CUV:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

We take the security of CUV and the software supply chain of C/C++ developers very seriously.

If you believe you have discovered a vulnerability or security issue:
1. **Do not create a public GitHub issue.**
2. Send an email to **`security@araskova.com`** with:
   - A description of the issue and potential impact
   - Steps to reproduce or a minimal proof of concept
   - Any suggested mitigations
3. You will receive an acknowledgment within 48 hours.
4. We will coordinate a patched release and publish a security advisory credit.

Thank you for helping keep the open source systems programming ecosystem safe!
